개인정보처리방침

IPO Calender Nino · 시행일 2026-10-02

1. 수집하는 정보

  • Google 계정 이메일 주소 — 어느 계정에 연결됐는지 앱 화면에 표시하기 위해서만 사용합니다.
  • OAuth 토큰 — Google 캘린더에 일정을 쓰기 위한 인증 토큰입니다.

그 밖의 개인정보(연락처, 다른 캘린더 일정, 파일 등)는 수집하지 않습니다.

2. Google 사용자 데이터의 사용

앱은 calendar.app.created 권한으로 이 앱이 만든 '공모주 달력' 캘린더에만 공모주 일정을 만들고, 고치고, 지웁니다. 사용자의 다른 캘린더나 일정에는 접근할 수 없습니다. IPO Calender Nino의 Google API 데이터 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 저장과 보관

이메일 주소와 토큰은 사용자 본인의 컴퓨터에 있는 설정 파일에만 저장되며, 외부 서버로 전송하거나 제3자에게 제공·판매하지 않습니다. 광고, 분석, AI 학습 등 다른 목적으로 사용하지 않습니다.

4. 삭제

앱의 '연결 해제' 버튼을 누르면 토큰이 폐기되고 저장된 정보가 삭제됩니다. Google 계정 → 타사 액세스에서도 언제든 권한을 철회할 수 있습니다. Google 캘린더의 '공모주 달력' 캘린더는 사용자가 직접 삭제할 수 있습니다.
